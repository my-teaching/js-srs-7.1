# СРС №7.1

## Мини-проект: каталог товаров средствами DOM

Это самостоятельная работа на закрепление уже пройденного материала. Новая тема здесь не вводится.

Используются:

- массивы и объекты;
- `forEach()`, `filter()`, `reduce()` и/или другие изученные способы обработки массивов;
- `Object.entries()`;
- `document.querySelector()`;
- `document.createElement()`;
- `textContent`, `classList`, `append()` / `replaceChildren()`.

## Что нужно сделать

Откройте `student-template.js` и заполните участки `TODO`. В результате `index.html` должен показывать:

- карточки всех товаров из исходного массива;
- количество товаров;
- количество товаров в наличии;
- сумму цен всех товаров;
- самый дорогой товар;
- количество товаров в каждой категории.

События, формы, `fetch()` и серверная часть для выполнения этой работы не нужны.

## Запуск

1. Откройте `index.html` в браузере и проверьте получившуюся страницу.
2. Откройте `test-runner.html`.
3. Добейтесь сообщения `Все тесты пройдены.`

`npm` и сторонние библиотеки не требуются.

## Что нельзя изменять

Не изменяйте имена и параметры функций `createProductCard`, `calculateStats`, `countByCategory`, `renderCatalog`, а также объект `window.domSrs`.

HTML-каркас и CSS можно изучать, но для выполнения работы их менять не требуется.

## Сдача

Работа выполняется в GitHub-репозитории. Отдельная загрузка в учебную систему не требуется, если преподаватель не сообщил иное.
